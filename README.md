# Баланс — план зарплаты

Статический русскоязычный дашборд для планирования месячного бюджета. Работает на GitHub Pages: серверная часть не нужна.

## Публикация

1. Загрузите `index.html` в корень GitHub-репозитория.
2. В репозитории откройте **Settings → Pages**.
3. В **Build and deployment** выберите публикацию из ветки и папку `/ (root)`.

Excel и CSV читаются в браузере на устройстве пользователя. Для XLSX библиотека SheetJS подключается с jsDelivr, поэтому при первом открытии нужен интернет. Для полной автономности можно сохранить библиотеку рядом и заменить адрес скрипта.

## Использование

- Нажмите «Выбрать файл» и выберите XLSX, XLS или CSV. Дашборд берёт первый лист и ищет столбец «после налога» (приоритетно), «заработано», «зарплата» или «доход».
- Для столбца дохода используется последняя сумма, если она похожа на итог; в противном случае — наибольшая сумма. Проверьте автоматически найденную сумму перед использованием.
- Если формат не распознан, впишите чистый доход вручную.
- Укажите обязательные расходы и настройте доли остатка по категориям. Значения по умолчанию: продукты 45%, развлечения 15%, прочее 20%, накопления 20%.

При открытии показана чистая зарплата 51 199,50 ₽ из файла YDENT.xlsx (колонка «после налога», строка итога); загрузка другого файла заменит её.

## Темы

Переключатель в правом верхнем углу включает тёмную или светлую тему. Выбор сохраняется в браузере. Дизайн использует фиолетово-розовую палитру и градиентные акценты.
